1 - O que são operações de “Commit”, “Push” e “Pop” efetuadas num repositório?

R1:
O Commit permite guardar as alterações feitas no repositório local, criando um registo que podemos consultar posteriormente para perceber o que foi alterado.

O Push é utilizado para enviar os commits do nosso repositório local para o repositório remoto, por exemplo, no GitHub ou GitLab.

Quanto ao Pop, no Git temos o comando git stash pop, que permite recuperar alterações que tínhamos guardado temporariamente com o git stash, retirando-as da lista de alterações guardadas, caso a aplicação seja bem-sucedida.


2 – Quais sáo as vantagens de usar Branchs num repositório git?

R2:
As branches permitem trabalhar em diferentes funcionalidades ou correções sem interferir diretamente com o código principal do projeto.

Por exemplo, quando estamos a desenvolver uma nova funcionalidade, podemos criar uma branch específica para esse trabalho, fazer os testes e, quando estiver tudo validado, integrar as alterações na branch principal.

Outra vantagem é que vários programadores podem trabalhar em tarefas diferentes no mesmo projeto, sem terem de alterar constantemente os mesmos ficheiros na branch principal.
